# EPOS Premium - Nueva Interfaz

Proyecto WPF .NET para la nueva aplicación POS de Windows. Este sistema es un Punto de Venta moderno que incluye pantalla de autenticación, menú principal interactivo y una interfaz de caja registradora funcional.

## Qué contiene
- `Views/`: Carpeta que contiene todas las pantallas del sistema (Login, Menú Principal, POS, Maestro de Clientes).
- `EPOS_NewUI.csproj`: proyecto WPF .NET[cite: 1].
- `App.xaml` / `App.xaml.cs`: arranque de la aplicación[cite: 1].
- `MainWindow.xaml` / `MainWindow.xaml.cs`: ventana principal inicial[cite: 1] que actúa como contenedor dinámico de las vistas.

## Requisitos para probar el sistema
Para poder ejecutar este proyecto en tu equipo, necesitas lo siguiente:
- **.NET SDK 9.0 está instalado en este equipo**[cite: 1] (o una versión compatible de .NET SDK instalada en tu sistema).
- Un editor de código. **VS Code puede usarse para editar el proyecto**[cite: 1] o Visual Studio 2022.
- Si usas VS Code, **se recomienda instalar la extensión de C# de Microsoft en VS Code para mejor experiencia**[cite: 1].

## Instrucciones de Instalación y Ejecución
1. Descarga el archivo comprimido desde Google Drive y extráelo en una carpeta de tu preferencia (por ejemplo, en el Escritorio o Documentos).
2. Abre la carpeta extraída usando Visual Studio Code (puedes arrastrar la carpeta al editor o usar `Archivo > Abrir carpeta...`).
3. Abre una nueva Terminal dentro de VS Code (`Ver > Terminal`).
